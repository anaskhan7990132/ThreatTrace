Detection Rules

TT-AUTH-001

Possible SSH brute-force activity

HIGH

Flag a source IP when the number of failed login events reaches the configured threshold inside a rolling time window.

CONDITIONfailed_login_count(ip, time_window) ≥ threshold

Why this rule exists

Repeated failures from one address over a short interval may indicate password guessing, a misconfigured service, or a user repeatedly entering an incorrect password. The grouping helps analysts prioritize investigation.

Known limitations

It does not correlate NATs, distributed attempts across multiple IPs, successful compromise, account lockouts, geolocation, or other telemetry. Missing or duplicated records affect counts. A threshold match is not proof of an attack.
